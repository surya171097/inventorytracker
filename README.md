# 📦Inventory Management System (Excel) FOR MY CLIENT  G FLURO COATINGS PVT LTD

An advanced Excel-based stock verification system with automated stock tracking using product codes. Built for real-time monitoring of **inward** and **outward** stock movements.

---

## 📊 Key Features

- ✅ **Dashboard Sheet** — Real-time stock summary and product-wise status
- ➕ **Inward Entry Sheet** — Add incoming stock entries
- ➖ **Outward Entry Sheet** — Record dispatched stock
- 🔄 **Auto-updates** — Total stock auto-calculated using Excel formulas
- 🎯 Ideal for: Warehouses, SMEs, and Logistic teams

---

## 🔗 How It Works

1. Enter product details in **Inward Entry**
2. Enter sales/dispatch data in **Outward Entry**
3. Dashboard auto-refreshes to reflect net stock levels
4. No VBA/Macro needed – 100% formula-based
